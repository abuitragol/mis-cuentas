# Mis Cuentas

Aplicación web para llevar contabilidad personal y de inmuebles (ingresos, gastos, contratos de arrendamiento, presupuestos y recordatorios), con adjuntos en foto o PDF. Los datos se guardan solo en el navegador de cada persona.

Ábrela en el navegador y, en iPhone o iPad, usa Compartir > Añadir a pantalla de inicio.
